## 👋 欢迎来到 Bingwu DevKit

这里是我的个人开发工具箱，收藏好用的开源项目，也开发自己每天会用到的工具。

把重复的配置沉淀为模板，把好用的方法整理成 Skills，让下一次开发更轻松。

## 🧭 项目导航

| 项目 | 用途 | 分类 |
| --- | --- | --- |
| [bingwu-workspace](https://github.com/bingwu-devkit/bingwu-workspace) | 个人项目创建 CLI，统一收藏和使用 GitHub 模板与 npm 脚手架 | 🛠️ 开发工具 |
| [starter-ts](https://github.com/bingwu-devkit/starter-ts) | TypeScript 库模板，集成 workspace、构建、测试和发布配置 | 🧩 项目模板 |
| [skills](https://github.com/bingwu-devkit/skills) | 可复用的 Agent Skills，整理开发经验与自动化工作流 | 🤖 AI Skills |

## ⚡ 从一个命令开始

使用 [bingwu](https://github.com/bingwu-devkit/bingwu-workspace) 交互选择模板，快速创建项目：

```bash
pnpm dlx bingwu-cli
```

模板使用方法见 [starter-ts](https://github.com/bingwu-devkit/starter-ts)，Skills 的说明与安装方式见 [Skills 文档](https://bingwu-skills.netlify.app)。
